## Как запустить  
1. Клонировать репозиторий: `git clone https://github.com/ArtemVay/Dart_Lab2.git`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`  
## Что изучили  
* создание классов
* работа с полями
* работа с конструкторами
* работа с методами
## Ответы на вопросы  
1. Поле живет в объекте, а переменная живёт внутри функции
2. Конструктор создает объект и задает начальные значения его полей
3. `@override` это проверка компилятором. Если его не указать, то опечатка создаст новый метод, вместо того чтобы переопределять старый
4. `static int _counter` принадлежит не объекту, а классу. Всего одна копия на всю программу
5. Нижнее подчёркивание в `_counter` означает приватность
